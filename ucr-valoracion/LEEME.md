# Portal de Valoración UCR · aplicación instalable (PWA)

Es el mismo portal de la carpeta del proyecto, preparado para instalarse como aplicación desde Chrome o Edge.

- Se instala desde la dirección web donde esté publicado: icono de instalar en la barra de direcciones, o botón "Instalar app" en Inicio.
- Funciona sin conexión una vez abierta la primera vez.
- No guarda datos propios: al pulsar "Abrir carpeta" trabaja con la carpeta Portal_Valoracion_UCR (en Drive o en el servidor que se decida).
- No contiene datos de deportistas. Sí contiene las tablas de referencia de dinamometría de la UCR y las instrucciones de los agentes, igual que el portal publicado en Claude.

Para publicar una versión nueva: sustituir index.html y cambiar VERSION en sw.js.
